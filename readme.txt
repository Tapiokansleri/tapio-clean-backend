Collapses plugin admin menus under a More accordion, tidies the admin bar, and moves admin notices into a Notifications hub.

== Description ==

Tapio clean backend keeps the WordPress admin focused on core workflows:

* **Sidebar More** — Core menus stay visible; plugin and custom post type top-level menus move under a collapsed **More** control above “Collapse menu”.
* **Admin bar More** — Plugin toolbar items collapse under **More**; core items and **Notifications** stay visible.
* **Notifications** — Admin notices are captured and shown from the admin bar instead of above page content.

Includes Finnish translations (`fi`, `fi_FI`).

== Installation ==

1. Upload the `tapio-clean-backend` folder to `/wp-content/plugins/`.
2. Activate **Tapio clean backend** through the Plugins screen.
